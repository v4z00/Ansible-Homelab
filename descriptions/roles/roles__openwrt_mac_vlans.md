# Role openwrt_mac_vlans

Role: `roles/openwrt_mac_vlans`.

Task names as written in the role:

- Zentrale Einstellungen pruefen
- MAC-Adressen validieren
- Verwaltete WLAN-Konfiguration abgleichen
- Geaenderte WLAN-Konfiguration aktivieren oder fehlgeschlagenen Reload nachholen
- Ergebnis anzeigen

The parameters list public role defaults. Internal facts, registered values and private host credentials are not form inputs.

## Parameters

The listed sources define these parameters. Missing documentation is indicated. Defaults are informational. Credentials are omitted.

## Sources and maintenance

- `roles/openwrt_mac_vlans/tasks/main.yml`

Maintain this description and its source hashes together when the code changes. The database stores a cache.
